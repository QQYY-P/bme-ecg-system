心电云端自动连接（2026-10-29）

文档已归入 docs/。下文未特别标注的源码、运行命令及本地目录均以“心电云端平台/”为基准；历史验证按原日期保留。

适用范围：这是 2026-10-29 的笔记本中转流程，保留用于旧环境复现。下文 localhost HTTP 入口和“未开放公网”是当时状态。当前账号登录使用 https://62.234.150.104/ ，现行部署与设备接入见同目录“云端工作台迭代.md”。

日常使用
1. 笔记本登录 Windows 后，连接助手自动在后台运行。
2. 笔记本保持联网，树莓派通过网线连接，固定地址 192.168.137.59。
3. 启动树莓派心电界面，右上角显示绿色“云端 ●”（宽屏显示“云端 · 在线”）。
4. 点击“云端”，选择记录，再点击“上传并分析”。
5. 如果记录正在采集中，会补传已保存数据，停止采集后自动分析。
6. 断线保留任务和原始数据，网络恢复后自动重试；退出界面后，下次打开继续未完成任务。

网页入口：http://127.0.0.1:8768/
手动唤起助手：双击“连接云服务器.cmd”，无需输入密码。
“手动连接云服务器.cmd”保留原来的管理连接方式。

连接方式
树莓派 127.0.0.1:8766 → 加密通道 → 笔记本 127.0.0.1:8768 → 加密通道 → 云服务器 127.0.0.1:8766。
因此笔记本需要开机登录并保持联网。服务器心电接口没有开放到公网。

权限与撤销
云端 ecg-tunnel 账号仅能转发到心电服务；树莓派 ecg-relay 账号仅能监听本机 8766。两个账号均禁止命令执行、密码登录和交互终端。
密钥保存在本目录 .cloud_private 中，仅当前 Windows 账号和 SYSTEM 可访问，不要打包或分享此目录。
连接状态：.cloud_private/auto_link_status.json。
自动启动入口：用户启动文件夹中的 ECG Cloud Auto Link.lnk。移除该快捷方式可关闭登录自启。
撤销云端授权：由管理员移除 /home/ecg-tunnel/.ssh/authorized_keys 中对应 ecg-auto-link 公钥。
撤销树莓派授权：由管理员移除 /home/ecg-relay/.ssh/authorized_keys 中对应 ecg-auto-link 公钥。
撤销授权后已有连接需由管理员终止该专用账号的 SSH 会话。

数据位置
树莓派完整云端返回结果：~/树莓派心电终端/data/cloud/results/<会话编号>.json
上传进度和待恢复任务：~/树莓派心电终端/data/cloud/
取消任务只取消后续上传和结果获取，不会删除已经上传的云端数据。
云端结果按完整会话计算，与本地实时推理分开展示，仅供课程研究。

断线重连修复（2026-10-31）
树莓派为 ecg-relay 专用账号设置每 15 秒检查连接，连续 3 次无响应后释放失效会话。
这样网线或笔记本连接中断后，旧通道不会长时间占用 8766 端口，自动助手可继续重连。
仍只允许原来的本机端口转发，账号权限不变。
