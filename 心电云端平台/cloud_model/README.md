# 云端模型适配与来源

[算法导航](../../docs/算法与评估.md) · [端侧模型](../../树莓派心电终端/cardioedge/README.md) · [云端快速开始](../docs/快速开始.md)

| 位置 | 职责 |
| --- | --- |
| [engine.py](engine.py) | 云端模型加载、会话分析与输入处理入口 |
| [vendor/](vendor/) | 固定版本的预处理、R 点、质量判断和 CardioEdge 数值实现 |
| [SOURCE.json](SOURCE.json) | 原始来源、上游提交、权重及每个文件的源/云端摘要、导入适配记录 |

`SOURCE.json` 的 `source_directory` 以仓库根目录为基准，而不是某台电脑的绝对路径。`upstream_commit` 指第三方模型上游提交，不代表本仓库终端代码始终与副本同步。云端文件按清单中的 `cloud_sha256` 核对；源文件曾经的摘要保留作为溯源依据。

副本用于使云端部署包自包含，运行时不跨目录导入树莓派工程。不同部署节奏下不自动覆盖副本，也不将 `vendor/` 当成可随意编辑的公共算法目录。

## 更新顺序

1. 明确要引入的终端版本，记录源提交或可追溯来源。
2. 核对许可，复制约定文件；记录包内相对导入适配。
3. 更新 `SOURCE.json` 的源/云端文件摘要及权重摘要。
4. 运行端侧和云端的相关数值、流式和输入门控测试；两个 Python 工程分开执行。
5. 检查云端打包清单；需要部署时另行记录版本、验收与回退。

模型开关为 `ECG_MODEL=cardioedge`，依赖见 [requirements-model.txt](../requirements-model.txt)。健康检查的模型状态与特定会话分析结果分别读取。
