树莓派固定 IP 与 VS Code 连接
验证日期：2026-10-27

适用连接方式：树莓派通过网线直接连接当前笔记本。

树莓派有线 IP：192.168.137.59
子网前缀：24（255.255.255.0）
笔记本以太网 IP / 树莓派网关：192.168.137.1
树莓派 DNS：192.168.137.1
登录用户名：pi2
VS Code Remote-SSH 主机名称：raspberrypi2

日常使用
1. 给树莓派供电，将网线连接树莓派与笔记本。
2. 等待树莓派启动完成。
3. 使用 E:\tool\VSCode-RaspberryPi2\Code.exe，连接 raspberrypi2。
4. 提示密码时输入树莓派账户密码。
无需每次执行 ip addr 命令。固定 IP 不等于免密码登录。

笔记本 SSH 配置已核对，位于 C:\Users\16236\.ssh\config：
Host raspberrypi2
    HostName 192.168.137.59
    User pi2
    Port 22

使用边界
此配置适用于当前笔记本 192.168.137.1/24 的网线直连网络。
以后如果改接路由器或换网段，应相应调整树莓派配置。
本地 SSH 连接不需要树莓派能访问互联网；通过笔记本上网仍需要 Windows 网络共享正常。
