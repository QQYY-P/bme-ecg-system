## 本轮结论

- QRS：44 条记录、22.07 小时、全长。150 ms 匹配条件下最高 F1 为 99.27%：现有 QRS（含质量门控）。这只是本轮公开数据条件下的排序。
- 当前分类完整链路：宏平均 F1 66.44%，N/S/V F1 分别为 95.21% / 23.85% / 80.28%；目标心搏覆盖率 96.30%。
- 参考 R 点对照：宏平均 F1 68.58%，覆盖率 98.40%。对照保留质量门控、输入处理与拒绝规则，用于定位误差来源，不是上游离线准确率的复现，也不保证每个类别都会变好。
- 候选检测器可作为后续云端算法接入依据；当前默认算法和分类权重本轮未替换。实际采集数据、其他数据库、噪声压力与临床有效性仍待验证。

## 统一条件与边界

- 数据：MIT-BIH 1.0.0；QRS 默认 44 条非起搏记录；分类默认上游 DS2 排除 202 的 21 条。本次实际请求为 QRS 44 条、分类 21 条，具体见逐记录表。201 与 202 来自同一人，而 201 在上游训练集合中。没有重新训练、调阈值或挑选最优测试片段。
- 360 Hz，按名称选择 MLII；记录 114 使用其第二通道。固定 `round(2048 + 200 × mV)`，限幅至 0–4095。三种检测器和两条分类路径使用同一量化波形，增益不按标注或逐记录统计调整。
- QRS 与分类均以包含边界的 ±54 点（150 ms）为主，±18 点（50 ms）作敏感性检查；使用 WFDB 一对一匹配，所有启动、末尾、质量拒绝时段的参考心搏均保留在分母。
- 现有 QRS 按 36 点块接收，保留生产质量门控。XQRS 保留内部滤波/学习；FastNVG 使用 NeuroKit2 `emrich2023` 清理与峰检测，不额外纠正伪迹。两者按整段输入，未附加生产质量门控。比较的是三条明确的处理路径，不是相同因果条件下只更换一个函数。
- 分类两条路径均执行现有 `StreamingClassifier`。诊断对照只提供专家心搏位置，待收到至少 0.4 秒后续数据才释放；不提供类别标签，不改变 8 秒上下文、滚动标准化或拒绝条件。
- 数据已公开且此前已用于项目探索；独立评测指独立执行固定实现，不能称为全新盲测、外部验证或实体设备验证。
