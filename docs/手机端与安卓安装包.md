## 账号管理与版本更新

使用者继续用账号密码登录，微信登录暂不实现。新版管理员功能包括搜索与筛选、创建校验、登录概况、重置密码、停用/恢复及撤销登录；操作说明见[管理员账号管理](../心电云端平台/docs/使用说明.md#管理员账号管理待部署)。普通账号只能查看自己的记录，公开下载不会开放其他人的心电数据。

手机浏览器/PWA 和 Windows 网页入口随服务器页面更新；Android 的页面打包在 APK 内，需服务器先支持新接口，再构建发布新版 APK。更新 APK 时沿用原签名、提高版本号并检查覆盖安装；仅刷新现有 APK 不会获得新的内置管理界面。具体交付状态见[更新日志](../CHANGELOG.md#当前交付状态)。

## 手机界面与合并

720px 及以下使用“记录、结果、账号”底部导航，记录纵向排列、搜索筛选可收起，结果优先显示测量总结，并提供波形和分析定位。记录读取失败可重试；日期范围错误不发请求。账号退出和切换清空移动导航、旧结果及错误状态。非结果页减少详情轮询，相同列表保留原按钮和焦点。

合并时保留电脑端窗口/幅度调整、心搏筛选、连接恢复和下载功能。分开手机/电脑导航元素标识，共用可折叠筛选面板；手机离开结果页时退出波形专注，防止记录列表继续隐藏。APK 的明确资源清单同步包含合并后的电脑与连接脚本，避免升级后缺少资源。

## 验证结果

- 完整云端回归 105 项、网页 57 项通过；包含 5 项安卓资源、manifest、唯一导航标识及 SDK 准备检查。
- Java 地址/路径策略 25 个用例通过；导出复制 6 个用例覆盖正常长度、未知长度、截断、超限、空内容和读取中断。
- 使用已安装 SDK/JDK 与原签名对重新构建；未下载新工具、未复制或输出私钥。最终 APK 编译、v2/v3 签名、zipalign、包名/版本/权限与资源清单检查通过。
- 本机隔离服务使用 24 条明确标记的合成记录。浏览器检查 320/390px 记录、结果、波形与底部导航，1440px 电脑布局无页面横向溢出。手机专注后返回记录正常；退出并换另一模拟账号后显示 0 条记录，旧结果已清空，预览控制台无错误。预览服务已关闭。
- 独立只读复核后，修复新克隆签名目录父目录缺失、合并资产遗漏、安卓 Windows 下载入口、设备凭据下载兼容及 CSV 不完整文件问题。CSV 先写私有临时文件，再校验并交付；失败尽力清理系统目标，无法清理会明确提示。缓存清扫仅每进程首次执行，写入目标前再次核对账号。

## 剩余验收与更新

这次发布为试用，未进行安卓实体手机安装/启动、登录、系统文件选择器、浏览器管理跳转、后台恢复、真实断网、覆盖安装或 iPhone 安装验收。浏览器窄屏检查与编译测试不能替代这些步骤，也不是人体或设备采集验证。

云端普通浏览器/PWA 仍使用已上线页面；新手机布局只有部署本次网页后才会出现在公网浏览器中，APK 则使用随包资源。代码合并不自动部署。

源码、安装和构建见 [安卓工程说明](../心电云端平台/android/README.md)。后续升级必须沿用原签名并增加版本编号；新克隆不得生成替代密钥覆盖旧安装。实际签名对保存在原项目被忽略的 `android/work/signing/`，工作树通过 `--signing-dir` 只读复用；私钥不随仓库或 Release 分发。
