## 手机界面与合并

720px 及以下使用“记录、结果、账号”底部导航，记录纵向排列、搜索筛选可收起，结果优先显示测量总结，并提供波形和分析定位。记录读取失败可重试；日期范围错误不发请求。账号退出和切换清空移动导航、旧结果及错误状态。非结果页减少详情轮询，相同列表保留原按钮和焦点。

合并时保留电脑端窗口/幅度调整、心搏筛选、连接恢复和下载功能。分开手机/电脑导航元素标识，共用可折叠筛选面板；手机离开结果页时退出波形专注，防止记录列表继续隐藏。APK 的明确资源清单同步包含合并后的电脑与连接脚本，避免升级后缺少资源。

- 完整云端回归 105 项、网页 57 项通过；包含 5 项安卓资源、manifest、唯一导航标识及 SDK 准备检查。

- 使用已安装 SDK/JDK 与原签名对重新构建；未下载新工具、未复制或输出私钥。最终 APK 编译、v2/v3 签名、zipalign、包名/版本/权限与资源清单检查通过。
- 本机隔离服务使用 24 条明确标记的合成记录。浏览器检查 320/390px 记录、结果、波形与底部导航，1440px 电脑布局无页面横向溢出。手机专注后返回记录正常；退出并换另一模拟账号后显示 0 条记录，旧结果已清空，预览控制台无错误。预览服务已关闭。
- 独立只读复核后，修复新克隆签名目录父目录缺失、合并资产遗漏、安卓 Windows 下载入口、设备凭据下载兼容及 CSV 不完整文件问题。CSV 先写私有临时文件，再校验并交付；失败尽力清理系统目标，无法清理会明确提示。缓存清扫仅每进程首次执行，写入目标前再次核对账号。
