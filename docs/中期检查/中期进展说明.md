# 冬学期中期进展说明

本页对应生物医学工程综合实践 2026 冬学期**中期检查（11-27）**，只汇总已经能指向证据的状态；未完成项单列，不用单次演示或软件测试替代实机验收。

## 一、本轮结论

1. 采集—端侧—云端—客户端四段链路均已入仓，Windows 免安装版与 Android 预发布包可下载。
2. 算法侧新增 **QRS/RR 公开数据评估**：10 条 MIT-BIH 记录，灵敏度 98.53%、阳性预测值 98.66%、F1 98.59%，报告与源码同源可复跑。
3. N/S/V 分类基线沿用秋学期结果（宏平均 F1 70.30%，S 类召回 27.06%），**S 类是当前明确短板**，本学期按误差归因而非直接调参推进。
4. **本机实跑**：云端 170 项、网页 101 项、终端 374 项自动化检查已在本机执行，详见[本机验证记录](本机验证记录.md)；9 项因本机沙箱禁止命名管道未通过，**不是代码缺陷**。
5. 实体 HDMI 全流程、长时运行、整机功耗、真机安装升级四类验收仍未闭环，均需实机或仪表。
