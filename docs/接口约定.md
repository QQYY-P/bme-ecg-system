# 接口约定与联调

基线日期：2026-11-23。这里提供共同索引；具体实现和测试仍是核对依据。修改接口时应在同一 PR 中列出发送方、接收方、兼容策略和测试。

## STM32 → 树莓派

| 项目 | 当前约定 |
| --- | --- |
| 串口 | USART1，115200，8N1，无流控 |
| 采样率 | 360 Hz |
| 每点格式 | `AA 55 MODE SEQ DATA_H DATA_L SUM`，7 字节 |
| MODE | 0：真实 ADC；1：板端模拟 |
| SEQ | 8 位，0～255 循环 |
| 数值 | 高字节在前；0～4095 有效，0xFFFF 无效 |
| 校验 | `(MODE + SEQ + DATA_H + DATA_L) & 0xFF` |
| 块 | 36 点，252 字节；接收必须支持任意拆分和合并 |

说明：`树莓派心电终端/docs/STM32串口对接说明.txt`、`硬件/STM32心电采集/Doc/2026-10-27_七字节串口协议.txt`。

验证：终端 `tests/test_protocol.py`、`tests/test_serial_connection.py`。8 位序号和累加校验不保证检测所有丢失或损坏。

## 采集 → 算法

原始 ADC、来源和质量标记保留；滤波、心率和模型结果作为派生结果。修改量纲、采样率、R 峰/窗口定义或模型标签时，需要同时更新端侧实现、云端适配及验证数据。

当前主模型位于终端 `cardioedge/`，云端副本位于 `cloud_model/vendor/`，来源与摘要见 `cloud_model/SOURCE.json`。旧 `models/` 用于历史原型和回归测试，不应与当前模型混用。同步云端副本时记录新旧摘要。

离线算法验证入口为 `心电云端平台/research/evaluate_ecg.py`；`requirements-research.txt` 只用于读取公开标注，不加入服务器运行依赖。输入为360Hz MIT-BIH通道0，固定200 counts/mV映射到ADC中点2048；不改变实采协议或现有模型输入。默认输出到被Git排除的 `outputs/qrs-hrv-evaluation/`；已审查的公开数据报告另存仓库 `docs/algorithm-validation/`。

R点和RR统计使用检测器的完整输出；不能用稀疏分类心搏替代。NN必须同时具有明确窦性节律和正常心搏标记，跨原始无效段、节律变化或被排除间期不计算连续差。未确认窦性时只称RR变异性，不把模型N类当作NN。报告的处理速度不包含模型分类、网络或排队，不能作为树莓派或公网容量结论。

## 树莓派 → 云端

原始块使用 ECGRAW01 v1/v2；头和行结构见两端的 `protocol.py`（终端上传部分为 `cloud/protocol.py`）。保持内容哈希校验、分块重传幂等和会话完成清单一致。

云端身份、设备授权和记录所有权由服务端校验。设备身份不得仅由请求正文中的编号决定；重传不得改变既有记录归属。

## 云端 → 网页

路由以 `心电云端平台/server.py`、`device_routes.py` 与 `tests/` 为准。现有接口覆盖会话列表、记录信息、设备状态和后台分析任务。多设备与手机功能的完成及部署状态以该模块的 `docs/云端工作台迭代.md` 为准，不将计划清单等同已上线功能。

对任何接口变更，在 PR 中记录：请求字段、响应字段、错误状态、旧客户端行为及迁移步骤。网页换账号、换设备或换记录时，旧请求结果不能覆盖当前选择。

### 管理员账号管理（2026-11-24，待部署）

`GET /api/admin/users` 保留 `users` 数组及每项 `id/username/is_admin/active`，新增 `created_at`、`last_login_at`（Unix 秒或 null）与 `active_sessions`（当前未过期且账号启用的浏览器登录数）。只有管理员可读；登录和 `/api/auth/me`、设备接收人列表不附带这些信息。有效登录不等于实时在线，也不等于物理设备数。旧账号未保存的时间为 null，不用迁移时间冒充历史创建或登录时间；失败登录不更新最近成功登录。

`POST /api/admin/users/{user_id}/revoke-sessions` 无必需请求体，返回 `{"revoked_sessions":整数}`，表示操作时撤销的未过期登录数；同时清理该账号过期登录。只允许管理员操作普通账号，沿用 Cookie/CSRF；未登录 401、普通用户或采集设备 403、缺少/错误 CSRF 403、用户不存在 404、目标为管理员 409。重复撤销可返回 0，不修改密码、启用状态、设备凭据/授权、记录和归属；允许用户随后重新登录，不承诺取消已获准执行中的业务请求。响应不写 Cookie，避免迟到响应覆盖其他页面的新登录。

创建账号仍用 `POST /api/admin/users`，账号去首尾空白并转小写，3–32 位 ASCII 字母/数字/横线/下划线且以字母/数字开头；密码 10–128 个字符，非法或重复账号 422。网页创建普通账号需要两次输入密码并阻止重复提交；重置密码与停用继续撤销原有登录，不删除账号或记录，管理员本身在此不可停用、重置或撤销登录。

升级自动创建独立 `user_activity` 表和会话查询索引，不改变旧用户表或原始数据。旧源码可继续运行及创建账号；回退期间不会维护新增统计，重新升级后缺失值继续显示未知，不回填虚构时间。部署前按既有流程备份数据库；手机/电脑网页随云端更新，内置网页的 Android APK 需要重新构建才包含新界面。本轮不部署、不发布安装包。

### 独立 QRS/RR 分析（2026-11-24，待部署）

网页/客户端使用 `POST /api/sessions/{id}/physiology-jobs` 提交，202 返回持久任务；`force=true` 可显式重算。`GET /api/analysis-jobs/{job_id}` 查询进度，任务新增 `kind=physiology`；旧分类任务为 `kind=model`，旧库启动时自动补齐，原分类接口不变。同一记录的两类任务独立去重，共用一个计算进程与 64 个活动任务上限。

`GET /api/sessions/{id}/physiology` 返回 `analysis_status`、`available`、算法版本/指纹、输入摘要、`summary`、`rr`、`hrv`、`performance`，尚未完成时不提供指标。`include_series=true` 另返回 `r_peaks`（原始 `sample_id` 与分析连续段 `segment_id`）和 `rr_intervals`（起止采样编号、毫秒值、是否接受、排除原因）；分析连续段编号不是上传段编号。默认汇总不携带明细序列。无可用 RR 时为 `ineligible`，未知数值为 `null`，不能按零或正常解读。

仅接收已完成清单校验、360 Hz、不超过 100 万点的记录。只分析 `serial/replay` 来源、`mode=0`、有效 ADC；跨采样编号/段内编号缺口、段变化、模式变化、中断/重同步标记、无效或质量不合格片段重置检测，不连接跨段 RR。接受区间为 280–2500 ms，标准差和相邻差指标仅称 RR 变异性；没有可信 NN 标记时 `hrv.status=unavailable`、`reason=normality_not_confirmed`、`metrics=null`，模型 N 类不构成 NN 依据。

权限沿用记录所有权，入队事务内重新验证设备凭据。未登录 401、其他账号记录/任务 404；未完成、已回收、依赖未就绪或超限 409；队列满 429。旧服务器缺少新接口时网页显示暂不可用，原分类与查看继续工作。运行依赖复用 `requirements-model.txt` 的 NumPy/SciPy，无需开启分类模型或安装 WFDB。

结果存放 `data/physiology/{session_id}/{source_digest}.json`，摘要包含原始清单、元数据、参数、算法源码及 NumPy/SciPy 版本；新版本不覆盖旧摘要，原始记录和旧分类不改写。备份应包含该目录及 `cloud.sqlite`。迁移后的两类任务不能交给旧工作进程混合运行，更新时先停止旧服务；回退需恢复升级前数据库与源代码备份，不能只替换服务文件。验证见云端 `test_physiology_analysis.py`、`test_physiology_tasks.py` 和网页 `physiology.test.cjs`。

电脑端公开下载：`GET /downloads/ecg-workspace-windows.zip` 返回客户端附件，`GET /downloads/ecg-workspace-windows.zip.sha256` 返回校验文本；不要求登录，仅映射服务器 `deploy/dist/desktop/` 下两份固定交付物。未知名称、文件缺失或符号链接返回 404，不提供目录遍历。个人记录及分析接口仍受账号所有权保护。旧客户端入口不受影响；部署需另行复制 ZIP/校验文件，源代码包不含二进制。验证见云端 `tests/test_desktop_web.py`、`tests/test_desktop_package.py`。
